# Basalt - Liquid Democracy Platform

This repository contains the Basalt application, a liquid democracy platform for crowdsourcing priorities from networks.

## Project Location

The main application is located in the `basalt/` directory.

See [basalt/README.md](basalt/README.md) for full documentation and setup instructions.

## Quick Start

```bash
cd basalt
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) to view the application.
